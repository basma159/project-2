🪑 Oak Furniture Landing Page
📖 Description

A modern and elegant landing page for a furniture store, designed to showcase furniture collections with a clean user interface and engaging CSS animations. The project focuses on creating an attractive shopping experience using only HTML and CSS.

✨ Features
Responsive page structure.
Multi-level navigation bar with dropdown menu.
Hero section with Call-to-Action button.
Product categories section.
Trending products showcase.
Product hover animations.
3D card flip effect.
Customer testimonial section.
Latest news section.
Newsletter subscription form.
Animated service icons.
Interactive footer.

HTML
CSS
Font Awesome
Google Fonts
💡 CSS Techniques Used
Flexbox
CSS Transitions
CSS Transform
CSS Animations
Hover Effects

Overlay Effects
